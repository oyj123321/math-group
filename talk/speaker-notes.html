第 3 / 15 页 · Route Switching Is a Symptom, Not a Verdict

ENWe have to keep two situations apart. One is the expert input: the features the chosen expert actually reads. The other is the route: which expert was chosen, and the weight on that expert. Once the input is perturbed, the prediction gets worse, and the expert often changes too. These two things happen together, so seeing a new expert does not mean the route caused the error.

中我们要考虑到不同的情况。一个是专家输入，被选中的专家真正读到的特征。一个是路由情况，选了哪个专家、权重是多少。输入一被扰动，预测变差，专家也常常换了。这两件事一起发生，所以说，不能看见换了专家就说是路由造成的。

第 4 / 15 页 · One Trained Model, Four Paired Evaluations

ENWe test those possibilities with four experiments on one trained model, and separate the two. Clean input with the clean route, and perturbed input with the perturbed route. The other two cells cross them. The order we report changes the features first and holds the route fixed: the perturbed features go to the expert the clean input would have chosen. The extra error there is the input effect. We then change the route to the expert and the weight chosen on the perturbed input. That piece is the routing effect. The two add up to the whole change in error from clean to perturbed.

中我们针对这些可能，用同一个训练好的模型做四个实验，把这两样拆开。干净输入配干净路由，扰动输入配扰动路由。另外两格是交叉的。报告的顺序是先改特征、路由先不变：扰动后的特征交给干净输入会选的那个专家，误差多出来的这一截叫输入效应。然后再改变路由，换成扰动输入会选的专家和权重，这一截叫路由效应。两个加起来就是从干净到扰动的全部误差变化。

第 5 / 15 页 · Fixed Input u, Four Distinct Maps

ENThis slide is what data we put the experiment on. The cue says which of four formulas to use: a sum, a contrast, a product, or the sine of that sum. The answer uses the same vector u each time, plus a nuisance vector v for interference. Because the data is synthetic, we can choose two kinds of perturbation on purpose. One perturbs only v. The other masks part of u, or removes the cue. In the shortcut setup, training secretly hides something related to the cue inside v, so the model might learn a shortcut. At test time we remove what was hidden there. Qianhui will now read the routing contribution in each case. Watch whether it is near zero, offsets the error, or adds to the error.

中这一页讲的是，我们把刚刚的实验放在什么样的数据上。cue 说明用四种算法里的哪一种：求和、对比、乘积，或者这个和的正弦。要算的是同一段向量 u，和用于干扰的 v。正因为是我们人造的数据，可以故意分两种扰动。一种只打乱 v。另一种遮住 u 里的一部分，或者擦掉 cue。shortcut 设定里，训练时偷偷在 v 里藏一点和 cue 有关的东西，让模型可能学会走捷径；测试时把这份偷偷塞进去的东西拿掉。千惠现在逐个读出路由项的贡献。请看它是接近零、抵消误差，还是加重误差。

第 8 / 15 页 · Information Loss Splits Into Two Regimes

ENNow we delete the task information. This experiment uses two methods. The first is a mask: the cue is kept, and we punch holes in u. As the mask grows, the input term goes from 0.16 to 0.59. Routing stays below 0.01, while the switch rate still rises from 0.12 to 0.27. Experts switch more often, but that barely changes the error. The extra error is reading incomplete numbers. The second method is cue deletion. With the cue off on half the items, the numbers stay, but the model does not know which formula to use. Input is 0.28 and routing is 0.15. Both add to the error. Restoring only the clean expert index, and keeping the perturbed gate weight, accounts for about 0.18. Here switching makes it worse, because the router was using the cue to choose.

中现在我们把任务信息删掉，本实验采取两种办法。第一种是掩码：提示保存，把 u 挖洞。掩码变大时，输入项从 0.16 到 0.59。路由项仍低于 0.01，切换率却从 0.12 升到 0.27。专家换得更高频了，但是几乎没再改对错。错是因为对着残缺的数字在算。第二种是删 cue：一半样本关掉 cue，保留数字，但不知道该用哪种算法。输入 0.28，路由 0.15，两项都在加重误差。只恢复干净专家编号、保留扰动后的门控权重，大约解释 0.18。这里换专家是在帮倒忙，因为路由器本来靠 cue 做选择。

第 13 / 15 页 · Three Takeaways From Fifteen Minutes

ENFirst. When noise makes the error larger, it is mainly because experts read dirty input. Second. Switching experts sometimes does almost nothing. Sometimes it reduces the error. Sometimes it makes the error worse. It depends on the test. Do not only look at how many times it switches. Third. We train it to switch less, but we still cannot say the prediction is more accurate.

中第一，噪声让误差涨，主要是专家读脏输入。第二，换专家有时几乎没作用，有时把损伤抵消，有时加重误差。要看具体测什么，不能只看换没换。第三，训练时让它少切换，还不能说预测更准。

第 14 / 15 页 · Boundaries of Our Scope

ENOur experiment has limits. One: only four small MLP experts. We use one expert at a time. This is not a big MoE like GPT. Two: when we split the error, we only use one order. If we change the order, the two parts can look different. Three: for real data, we only test one SARCOS robot arm. It may not work the same on other data.

中关于我们实验的不足：1.只有 4 个小 MLP 专家，每次只走一个专家，不是 GPT 那种大 MoE。2.拆误差时只固定了一种顺序。换顺序可能把同一份误差拆成不一样的比例。3.真数据只验了 SARCOS 一条机械臂，可能缺乏泛化性。

Do Anh Dung · 定义和实验设计

第 3 页 · 切换率为什么不是解释？

也可能问：You showed that experts switch. Isn’t that the mechanism?

ENThe switch rate counts how often the top-1 expert changes. It does not say what that change did to the error. The new route can add error, offset it, or make no detected difference. The four-cell contrast is what measures that contribution.

中切换率只计算 top-1 变了多少次，不说明这次变化对误差做了什么。新路由可以加重误差、抵消误差，或没有被检出的差别。算出这份贡献的是四格对比。

不要说：路由不重要，或者切换没有意义。

第 4 页 · 四个格子到底在比什么？干净路由是最优的吗？

也可能问：Is L10 a route the model would actually choose?

ENOne trained model, target fixed. The input term changes the features and keeps the clean expert and the clean gate weight. The routing term then lets the index and the weight become the ones chosen on the perturbed input. We do not claim the clean route is optimal. If routing is negative, putting it back increases error.

中同一个模型，标签不动。输入项只换特征，专家编号和门控权重保持干净值。路由项再换成扰动输入会选出的编号和权重。干净路由不是最优。路由项为负时，换回去会让误差变大。

不要说：这是路由器自己会走的一条部署策略。

第 4 页 · 为什么不训练四个模型？

ENThe question is what one route change does inside a fixed model. Four separately trained models would mix training noise into the contrast.

中问题是同一次路由变化在固定模型里对误差贡献多少。分开训练的四个模型会把训练噪声混进对比。

第 5 页 · Shortcut 里 cue 还在，这还算捷径吗？

ENThe explicit cue stays visible in both profiles. The shortcut is an extra training offset, twice the cue, on nuisance coordinates. The test set removes that offset. So the clean shortcut test has already lost the training shortcut. Later noise and shifts are paired with that clean test.

中两种剖面里，显式 cue 都还在。捷径是训练时加在干扰坐标上的两倍 cue。测试集把这个偏移拿掉。所以 shortcut 的干净测试已经失去了训练捷径，后面的噪声和移位都是相对这个干净测试。

不要说：模型在测试时看不见任务，只能靠捷径。

第 5 页 · 第四个任务不就是第一个的正弦吗？

ENYes. f1 and f2 are two linear directions, f3 needs a product, and f4 applies a sine to the same projection as f1. The point is four maps on one u, not four unrelated datasets.

中是的。f1 和 f2 是两个线性方向，f3 需要乘积，f4 是对 f1 同一个投影做正弦。要点是同一个 u 上的四种映射，不是四份互不相关的数据。

向丽千惠 · 分解结果

第 6 页 · 0.579 和 +0.326 很强，相关 0.11 是不是说专业化没用？

ENSpecialization is real: one expert receives 0.579 of a regime’s routes, and removing it raises MSE by 0.326. That cost correlates only 0.11 with noise error. Clean-task dependence is a weak guide to noise robustness.

中专业化是真的：一个专家接到该状态 0.579 的路由，拿掉后 MSE +0.326。这个代价和噪声误差只相关 0.11。干净任务上的依赖，不太能预测噪声稳健性。

不要说：专家没有分工。

第 7–8 页 · +2.33 是不是很大？和后面的 0.59 怎么比？

ENDifferent scales. +2.33 is a change in MSE times 10,000, so about 0.000233. The mask numbers are raw MSE, on the order of tenths. The nuisance effect is the smaller absolute change.

中刻度不同。+2.33 是 MSE 变化乘以 10,000，大约 0.000233。掩码那些数是原始 MSE，量级是十分之几。干扰效应的绝对变化更小。

第 7 页 · 前三行路由区间包含 0，最后一行又抵消了误差。哪个对？

ENBoth, on different rows. On nuisance noise and shift, the routing interval includes 0. On the shortcut shift, routing is −2.29×10−4 and the interval excludes 0. The switch rate cannot tell those rows apart.

中两行都对，但是不同的行。干扰噪声和移位上，路由区间包含 0。Shortcut 移位的路由项是 −2.29×10−4，区间不含 0。切换率分不出这些行。

不要说：路由从不重要。也不要把 2.33 和 2.29 说成正好相等。

第 7 页 · 区间这么宽，抵消成立吗？包含 0 是不是没有效果？

ENThe sizes are uncertain. The directions are established. Input is entirely above 0, routing entirely below 0, and the total interval contains 0. An interval that contains 0 means the direction is not established. It does not prove the effect is zero, and it does not prove two methods are equivalent.

中大小不确定，方向是确定的。输入整个在 0 以上，路由整个在 0 以下，总和的区间包含 0。区间包含 0 只是没有确立方向，不是证明效果为零，也不是证明两种方法等价。五个种子和交叉 bootstrap 是区间宽的原因。

第 8 页 · 掩码上切换从 0.12 到 0.27，路由项为什么还小于 0.01？
